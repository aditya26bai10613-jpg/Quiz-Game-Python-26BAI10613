# Project Statement

## Project Title
Quiz Game - Interactive Multiple Choice Quiz in Python

## Problem Statement
Students often need a quick way to test their knowledge before examinations. Manual quizzes require preparation and checking, while a simple computer-based quiz can provide immediate feedback and a score. This project addresses that need through a console application that asks multiple-choice questions, checks answers, and reports performance.

## Scope
The project is a single-user console application. It supports quiz attempts, question-bank viewing, adding new questions, input validation, score calculation, and persistent question storage using JSON.

## Target Users
- Students
- Beginners learning Python
- Teachers demonstrating basic programming concepts

## High-Level Features
1. Start a random quiz.
2. Answer multiple-choice questions.
3. Receive immediate feedback.
4. View score, percentage, and grade.
5. Add new questions.
6. View all stored questions.
7. Persist the question bank in JSON.
